# Sites/Domain-Bundle Data Model
Label: wayfinder:research

## Question
Produce the sites.json structure for curated domain bundles (~30-50 common distracting sites, each with its full known domain set e.g. YouTube: youtube.com, m.youtube.com, ytimg.com, googlevideo.com) plus the schema for user-added manual/custom domain entries as a fallback. Include update/versioning approach for the bundled file.
